## 1. Назначение программы

Программа «Mahalanobis Concept Drift Detector» предназначена для автоматической детекции концептуального дрейфа в потоках текстовых данных на основе многомодальной метрики Махаланобиса в пространстве эмбеддингов трансформерных моделей.

Программа обеспечивает выявление статистически значимых отклонений входных данных от обученного распределения без дополнительного дообучения модели.

Опционально поддерживается **обучаемый нейросетевой проектор** (`DeepMahalanobisProjector`), который отображает высокоразмерные эмбеддинги (например, 384 или 768 измерений) в компактное пространство. Это снижает влияние плохой обусловленности ковариаций и «проклятия размерности» на оценку расстояния Махаланобиса. Проектор обучается отдельно (triplet-loss на размеченных данных), затем передаётся в детектор при создании или восстанавливается при загрузке модели из файлов `*_projector.pt` и `*_projector_config.json`.

---

## 2. Функциональные возможности

Программа реализует следующие функции:

1. Преобразование текстовых сообщений в векторные представления фиксированной размерности.
2. Формирование статистической модели нормы для каждого семантического кластера.
3. Вычисление расстояния Махаланобиса до каждого кластера.
4. Определение ближайшего кластера.
5. Расчёт адаптивного порога детекции.
6. Определение наличия концептуального дрейфа.
7. Формирование числовой оценки степени отклонения.
8. (Опционально) обучение и применение проектора эмбеддингов для работы Махаланобиса в пространстве пониженной размерности.

- Оперативная память: не менее 8 ГБ

## 5. Порядок работы программы

### 5.1 Этап построения модели нормы

1. Загрузка обучающего набора данных.
2. Преобразование текстов в эмбеддинги фиксированной размерности (один проход по всей выборке).
3. При использовании проектора — отображение эмбеддингов в подпространство меньшей размерности (инференс обученной сети).
4. Для каждого кластера вычисляются:
   - средний вектор;
   - ковариационная матрица;
   - регуляризованная ковариационная матрица;
   - статистический порог детекции.

Результатом этапа является модель «нормального» распределения данных.

**Обучение проектора (отдельный шаг):** скрипт `scripts/train_projector.py` строит эмбеддинги SBERT по размеченному CSV и обучает MLP с потерями triplet margin, сохраняя веса (`.pt`) и JSON с гиперпараметрами архитектуры. Подробности — в [api_reference.md](api_reference.md) (раздел про `projection` и `train_projector.py`).

---

### 5.2 Этап детекции

Для нового текстового сообщения выполняются следующие действия:

1. Вычисляется эмбеддинг.
2. При наличии проектора — применяется проекция к вектору признаков.
3. Рассчитываются расстояния Махаланобиса до всех кластеров.
4. Определяется ближайший кластер.
5. Вычисляется минимальное расстояние.
6. Выполняется сравнение с порогом.
7. При превышении порогового значения фиксируется наличие концептуального дрейфа.

## 6. Выходные данные

Результатом работы программы являются:

- идентификатор ближайшего кластера;
- минимальное расстояние Махаланобиса;
- значение порога детекции;
- бинарный индикатор наличия дрейфа;
- числовая оценка величины отклонения.

Пример вывода:

cluster_id: 2
distance: 11.84
threshold: 8.97
drift: True
score: 2.87

## 7. Ограничения и особенности

1. Для корректной работы требуется наличие обучающей выборки достаточного объёма.
2. При малом количестве данных возможна нестабильность ковариационных оценок.
3. Для высокоразмерных эмбеддингов обязательна регуляризация ковариационной матрицы; использование проектора уменьшает эффективную размерность и может улучшить устойчивость оценок.
4. Программа не выполняет автоматическое дообучение модели эмбеддингов SBERT; проектор — отдельная малая сеть, обучаемая скриптом `train_projector.py`.
5. Сохранённая модель с проектором требует согласованности версии PyTorch и наличия файлов `*_projector.pt` и `*_projector_config.json` рядом с `.joblib`.
